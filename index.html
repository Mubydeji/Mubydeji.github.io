WhereHow it breaksWhat I do about it

1 In the clinic

A page gets skipped. Last month's figures get copied into this month.

I supervise collection in 130+ facilities and have checked registers in more than 30 of them myself. My repeat check on stock records flagged 44 of 242 facilities.

2 On the phone

A thumb slips on the form and 48 becomes 84.

I design the ODK forms to refuse it, with range checks and rules that compare one answer with another. One of my forms has 60 variables.

3 On the way in

Register photos pile up on the server. Some get copied twice and some never arrive.

My pipeline moves only the new files, several at a time, and retries the ones that fail. A run of about 1,500 files used to take 45 minutes. It now takes a few.

4 In the database

A file loads twice. Half a file loads and nobody notices.

Every load I write is logged, checked for duplicates first, and counted row by row after. Stock reports from 255 facilities go through this each month.

5 In the report

The register and DHIS2 disagree, and the report quotes the wrong one.

I match the two facility by facility, go back to the register photo where they differ, and write up what I find for leadership.

Once the data is sound, I model it. See the projects.

Chest X-ray pneumonia classifier

PyTorch, ResNet-50, EfficientNet-B0, Grad-CAM, FastAPI, Docker

The dataset comes with a problem. Its validation folder holds 16 images, and one patient's X-rays can sit in both the training and test folders. A model can then score well by recognising the patient. So before training anything, I grouped all 5,856 images into 2,790 patients and split by patient.

I trained two models the same way and set each threshold to miss fewer pneumonia cases. Grad-CAM showed me where the model looks. On many images it looks near the middle of the chest and not at the lungs, and the write-up says so.

Clinical NLP validator

Python, Groq API, Llama 3.3, Streamlit

A language model reads a clinical note and returns 11 fields, such as the diagnosis and the follow-up date. How often is it wrong? This tool scores every field against the right answer as correct, wrong, missing or invented.

News classification, four methods compared

scikit-learn, Word2Vec, DistilBERT, Llama 3.1

I sorted 2,225 BBC News articles into five categories using four methods. All four got the same split and the same 334 test articles.

The plainest method won. Word counts with logistic regression beat a fine-tuned DistilBERT, and it trained in seconds on a CPU. Sport and tech articles share few words, which helps a method that counts words.

Nftify, question answering from documents

Python, ChromaDB, Sentence Transformers, Gemini, Streamlit

Ask a general chatbot about Click-On Kaduna and it guesses. Nftify looks the answer up first, in pages I scraped and indexed. Then it writes an answer from what it found and lists the sources.

If the answer is not in the pages, it says so.

Open the app Code

What happens when you ask a question

  1. The question is turned into a vector with all-MiniLM-L6-v2.
  2. ChromaDB finds the closest chunks of text. Each chunk is 900 characters, with a 150-character overlap.
  3. The top 3 to 8 chunks go to Gemini 2.5 Flash with the question.
  4. Gemini answers from those chunks only, and the app shows the sources.

Healthcare A/B testing framework

Python, SciPy, Statsmodels

I simulated a trial on 768 patients to practise running one properly. I set the hypotheses first, then ran a power analysis, three tests per measure, confidence intervals and effect sizes.

Both groups came from one population, so the correct result is no difference. That is what it found.

Filling gaps in past survey submissions 51 submissions across 17 rounds, with a check that stops on any mismatch.
  1. Rules file
  2. Dry run
  3. Backup
  4. Write
  5. Read back and compare
Problem
Past submissions had blank answers that had to be filled on the server without damaging the records.
What I built
A Python notebook on the ODK Central API with a rules file, a dry run, a backup, and a read-back check that stops the run on any mismatch. A second, read-only notebook finds unanswered fields by testing each form rule against every submission.
Result
Blank answers filled in 51 submissions across 17 rounds. I also compared a QA file with the ticked answers in 119 cases. The server values matched the ticked answers in 110, so I reported that the QA file may be the weaker source.
